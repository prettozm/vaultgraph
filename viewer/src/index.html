VAULT GRAPH

Read the graph a repository already exposes in its .vault-graph/ folder.

Public repositories work with no token. For a private repository, paste a fine-grained token (Contents: read on that repo); it is stored only in this browser and used to read the graph via the authenticated GitHub API. For a private repo, point at the branch that carries .vault-graph/, e.g. …/tree/<branch>. You can also paste a direct manifest.json URL (handy for local use).

Create one at GitHub → Settings → Developer settings → Fine-grained tokens.
